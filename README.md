## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Shyamganesh-217/Portfolio.git

# Navigate into project directory
cd Portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Building for Production
```bash
npm run build
```
